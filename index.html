Como configuro o BlackInk?
Safe/offer (ou Clone) → regras → destino do anúncio = URL BlackInk. ~15 min · sem OAuth.
O que é um cloaker?
Camada server-side entre o clique e a página final: bots/VPNs/revisores veem safe page; tráfego qualificado vê offer page.
O que é safe page e offer page?
Safe page para tráfego inválido (compliant). Offer page só para quem passa no filtro. Roteamento server-side <50ms.
Já uso outro cloaker. É difícil migrar?
